# 접근성 트랙 — 2장. 한 손 키보드 / 음성 코딩 (Talon, Cursorless) 입문

> 손을 자유롭게 못 쓰시거나 키보드 부담을 줄이고 싶으실 때 쓰시는 도구들입니다.

이 챕터는 **40분**이면 끝납니다. 도구가 본격적이라 바로 익숙해지지는 않으시지만, 큰 그림은 잡으실 수 있어요.

---

## 시작 전에

음성으로 코드를 작성하는 시대입니다. 손목 통증, 부상, 기타 운동 제약이 있으셔도 코드를 쓰실 수 있어요. 한 손만 쓰시거나, 손 대신 음성을 쓰시거나, 둘을 함께 쓰시는 분도 계세요.

오늘 다루는 도구는 다 무료 오픈소스이고, 학습 곡선이 좀 있지만 한 번 익히시면 평생 쓰실 수 있습니다.

---

## 1. Talon (음성 + 눈 추적)

### Talon이란

- **음성 명령**으로 컴퓨터 전체를 조작
- **눈 추적기**(있으시면)로 마우스 대체
- 코드 편집, 파일 관리, 웹 브라우징 모두 가능

```
talonvoice.com
```

### 가격

- 기본 기능: **무료**
- 빠른 음성 인식 모델 (Conformer): 후원 회원 대상 ($15/월~)

### 학습 곡선

처음 1~2주는 손 코딩보다 느립니다. 1~3개월 후부터 본인 워크플로우가 자리 잡으면 손 코딩과 비슷하거나 더 빨라지신 분도 많습니다.

### 시작 단계

1. talonvoice.com에서 본인 OS용 다운로드
2. 마이크 권한 허용
3. 기본 명령 익히기:
   - "press tab"
   - "save document"
   - "scroll down"
4. 본인이 자주 하는 작업 위주로 명령 추가

## 2. Cursorless (음성 코딩 특화)

### Cursorless란

- VS Code 확장
- 코드의 모든 토큰(변수, 함수 등)을 음성으로 가리키기
- Talon 위에서 동작

```
cursorless.org
```

### 동작 예시

```
"chuck this token"      → 현재 토큰 삭제
"copy that air"         → 색이 있는 'air' 토큰을 복사
"chunk those harp"      → 'harp' 토큰들의 묶음 삭제
```

VS Code 화면에 작은 색 표시가 떠서 본인이 음성으로 가리킬 수 있게 도와줍니다.

### 학습 곡선

Talon과 함께 1~3개월. 한 번 익히시면 손으로 코딩하는 것보다 빠른 속도가 가능하다고 사용자분들이 후기 남기십니다.

## 3. Vim Speak (음성 + Vim)

Vim을 쓰시는 분이라면 **Vim Speak**나 **Talon Vim Plugin**이 있습니다. Vim의 키 명령을 음성으로 발화하실 수 있어요.

```
"hop to next word"      → w
"down five"             → 5j
"yank line"             → yy
```

## 4. 한 손 키보드 옵션

음성이 어려우신 환경(공공장소, 도서관)에서는 한 손 키보드가 좋습니다.

### 하드웨어

- **Maltron 한 손 키보드** — 손 모양에 맞춘 인체공학 디자인
- **Frogpad** — 작고 가벼움
- **Kinesis Half Keyboard** — 표준 한 손 키보드

### 소프트웨어 (기존 키보드를 한 손용으로)

- **One-Hand Keyboard for Windows** — 무료
- **macOS의 단축키 매핑** — Karabiner Elements

## 5. 본인 워크플로우 만들기

음성·한 손 도구는 본인이 자주 하시는 작업에 맞춰 **명령을 직접 추가**하시는 게 핵심입니다.

### 자주 추가되는 명령

- `git commit` 한 번에 — "commit changes"
- 자주 쓰는 함수 호출 — "call my function"
- 본인 이름 입력 — "say my email"

처음에는 기본 명령으로 충분하시고, 점점 본인 명령을 추가하시면 됩니다.
