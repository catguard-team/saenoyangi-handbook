# 접근성 트랙 — 3장. 큰 글씨 + 고대비 화면 셋업

> 저시력·시각 피로가 있으시거나, 단순히 더 편하게 보고 싶으신 분을 위한 화면 설정입니다.

이 챕터는 **20분**이면 끝납니다.

---

## 시작 전에

화면이 잘 안 보이실 때 안경 도수를 올리시기 전에 컴퓨터 설정을 먼저 보시면 좋습니다. **무료로 30분 안에** 화면을 본인에게 맞게 만드실 수 있어요.

---

## 1. 글씨 크게 만들기

### macOS

1. 시스템 환경설정 → **디스플레이**
2. **확대/축소** 또는 **해상도 변경** → 더 큰 텍스트 옵션
3. 또는 **손쉬운 사용** → **확대/축소** → 옵션 조정

### Windows

1. 설정 → **접근성** → **텍스트 크기**
2. 슬라이더를 오른쪽으로
3. **적용** 클릭

### 빠른 단축키 (한 화면만)

| OS | 키워드 |
|----|--------|
| macOS | Cmd + + (현재 화면 확대), Option + Cmd + + (전체 확대) |
| Windows | Ctrl + + (현재 페이지 확대), Win + + (돋보기) |

## 2. 고대비 화면

### macOS

1. 시스템 환경설정 → **손쉬운 사용** → **디스플레이**
2. **대비 증가** 켜기
3. **반전** 옵션도 시도해 보세요 (검정 배경 + 흰 글씨)

### Windows

1. 설정 → **접근성** → **고대비**
2. **고대비 모드** 켜기
3. 테마 선택 — "고대비 검정"이 가장 일반적

## 3. 다크 모드 (눈 피로 줄이기)

| OS | 위치 |
|----|------|
| macOS | 시스템 환경설정 → 일반 → 모양 → "어둡게" |
| Windows | 설정 → 개인 설정 → 색 → 모드 선택 → "어두움" |

다크 모드는 야간 사용에 특히 도움이 됩니다.

## 4. 코딩 환경 (VS Code 등) 설정

### VS Code 폰트 크기

1. **Ctrl/Cmd + ,** (설정 열기)
2. "font size" 검색
3. **Editor: Font Size**를 18~24로 조정

### VS Code 고대비 테마

1. 좌측 사이드바 → 확장 프로그램 (Extensions) 아이콘
2. "high contrast" 검색
3. 마음에 드는 테마 설치 → 적용

기본으로 들어 있는 **High Contrast Black** 테마도 충분합니다.

### 줄 간격

1. 설정에서 "line height" 검색
2. **Editor: Line Height**를 1.5~2.0 사이로

줄 간격이 넓으면 코드가 시원해 보입니다.

## 5. 색맹·색약 친화 설정

### 색 인식이 어려우실 때

| OS | 도움이 되는 설정 |
|----|---------------|
| macOS | 손쉬운 사용 → 디스플레이 → **색상 필터** |
| Windows | 접근성 → **색상 필터** |

본인 색 인식 유형(적록·청황 등)에 맞는 필터를 선택하시면 화면 색이 조정됩니다.

### 코드 에디터에서

- **색 의존을 줄이는 테마** 사용 (예: Monokai Dimmed, Solarized)
- 에러는 색 + **밑줄**로 표시되는 옵션 켜기
- Git diff는 색 + **+/-** 기호 함께

## 6. 폰트 추천 (가독성)

가독성이 좋다고 알려진 폰트들:

| 폰트 | 비고 |
|------|------|
| **Atkinson Hyperlegible** | 시각 장애인 대상 디자인. 무료 |
| **APHont** | American Printing House for the Blind 제작 |
| **OpenDyslexic** | 난독증 친화 |
| **D2Coding** | 한국어 + 코드 친화. 무료 |

VS Code 설정 → "font family"에서 변경 가능.

## 7. 화면 휴식 — 눈 보호

오래 화면을 보시면 누구나 눈이 피곤해집니다.

### 20-20-20 규칙

### 자동 알림 도구

- 또는 휴대폰 알람을 25분마다
