# 접근성 트랙 — 1장. macOS·Windows 화면읽기 (VoiceOver / 내레이터) 켜기

> 화면의 글자를 음성으로 읽어주는 기능입니다. 처음 시작하시는 분을 위한 안내예요.

이 챕터는 **30분**이면 끝납니다. 본인 페이스로 가셔도 됩니다.

---

## 시작 전에

이미 화면읽기 도구를 쓰고 계시는 분은 이 챕터를 건너뛰셔도 됩니다. 처음 시작하시거나, 가족·동료 분께 설명하실 일이 있으시면 참고해 주세요.

화면읽기 도구는 화면의 글자·버튼·이미지 정보를 음성으로 읽어줍니다. 코딩을 하시면서 음성 출력으로 코드 구조를 파악하시는 분들도 많습니다.

---

## 1. macOS — VoiceOver

### 1-1. 켜기

```
Cmd + F5
```

또는 시스템 환경설정 → 손쉬운 사용 → VoiceOver → "VoiceOver 사용" 켜기.

처음 켜시면 안내 튜토리얼이 시작됩니다. 들으시면서 따라가 보세요. 30분 정도 걸려요.

### 1-2. 끄기

같은 단축키 (Cmd + F5)를 다시 누르시면 됩니다.

### 1-3. 자주 쓰시는 단축키

VoiceOver의 기본 보조 키는 **Caps Lock** 또는 **Control + Option** 입니다. (이걸 "VO 키"라고 부릅니다.)

| 동작 | 단축키 |
|------|--------|
| 다음 항목 | VO + → |
| 이전 항목 | VO + ← |
| 활성화 (클릭) | VO + Space |
| 모두 읽기 | VO + A |
| 빠르게 / 느리게 | VO + Cmd + ↑ / ↓ |

### 1-4. 코딩 환경에서

- **Xcode** — VoiceOver와 가장 호환성이 좋음
- **VS Code** — `editor.accessibilitySupport` 설정을 `on`으로
- **터미널** — 기본 지원

## 2. Windows — 내레이터

### 2-1. 켜기

```
Win + Ctrl + Enter
```

또는 설정 → 접근성 → 내레이터.

### 2-2. 끄기

같은 단축키 (Win + Ctrl + Enter)를 다시.

### 2-3. 자주 쓰시는 단축키

Windows의 보조 키는 **Caps Lock** 또는 **Insert** 입니다. ("내레이터 키"라고 부릅니다.)

| 동작 | 단축키 |
|------|--------|
| 다음 항목 | 내레이터 키 + → |
| 이전 항목 | 내레이터 키 + ← |
| 활성화 | Enter |
| 모두 읽기 | 내레이터 키 + R |
| 빠르게 / 느리게 | 내레이터 키 + + / - |

### 2-4. NVDA (무료, 더 강력)

내레이터보다 NVDA가 코딩에 더 적합한 경우가 많습니다.

```
nvaccess.org/download
```

무료 오픈소스이고, 한국어를 잘 지원합니다.

## 3. 코드 읽기 효율 팁

### 3-1. 들여쓰기 알림

Python처럼 들여쓰기가 중요한 언어는 **들여쓰기 단계를 음성으로 알려주는 옵션**을 켜시면 좋습니다.

- VoiceOver: VoiceOver 유틸리티 → 자세한 정보 → 텍스트 → 들여쓰기 알림
- NVDA: NVDA 메뉴 → 환경 설정 → 문서 형식 → 들여쓰기 변경 시 알림

### 3-2. 음성 속도

처음에는 느리게 시작하셔도 됩니다. 익숙해지시면 점점 빠르게 (3~4배까지) 올리시는 분이 많아요.

### 3-3. 키보드 우선

마우스보다 **키보드 단축키** 위주로 작업하시는 게 화면읽기와 잘 맞습니다.

## 4. GitHub과 화면읽기

GitHub은 화면읽기를 비교적 잘 지원합니다.

- 키보드 단축키: GitHub 페이지에서 `?` 누르시면 단축키 목록
- 코드 보기: `t` 키로 파일 검색
- PR 리뷰: `j` / `k`로 변경 사항 이동

## 5. 막히실 때

| 증상 | 해보실 것 |
|------|----------|
| 음성이 너무 빨라요 | 위 4-2 (단축키)로 속도 조절 |
| 일부 버튼을 안 읽어요 | 그 사이트의 접근성이 안 좋은 거예요. 5장에서 신고하는 법 배움 |
| 한국어를 영어로 읽어요 | VoiceOver/NVDA 음성 설정에서 한국어 추가 |
