# 접근성 트랙 — 4장. 자막 자동 생성 도구로 강의 영상 보기

> 청각 접근성 + 학습 효율 모두에 도움이 되는 자막 도구들입니다.

이 챕터는 **30분**이면 끝납니다.

---

## 시작 전에

영상에 자막이 없거나, 한국어 자막이 없는 영어 강의를 보고 싶으실 때. 또는 청각 장애가 있으시거나 청각 피로가 있으실 때. **자동 자막 생성 도구**가 큰 도움이 됩니다.

요즘 자막 자동 생성 정확도는 한국어 90%, 영어 95% 수준까지 올라왔습니다. 완벽하지는 않지만, 학습에 충분한 정확도예요.

---

## 1. YouTube 자동 자막 (가장 쉬움)

### 켜기

1. 영상 하단의 자막 (CC) 버튼 클릭
2. 자막이 안 뜨면 **설정 톱니바퀴** → **자막** → **자동 생성** 선택

### 한국어 영상 → 영어 자막

1. 자막 → **자동 번역** → 영어 선택
2. 영어 영상도 → 자동 번역 → 한국어 가능

번역 정확도는 매우 높지는 않지만, 큰 의미 파악은 가능합니다.

### 자막 크기·색 조정

자막 설정 → 옵션 → 글자 크기, 배경 색, 글자 색 등 조정 가능.

## 2. 라이브 자막 — 회의·강의에서

### macOS의 라이브 자막

```
시스템 환경설정 → 손쉬운 사용 → 라이브 자막
```

화면 전체에서 들리는 음성을 자막으로 변환해 줍니다. Zoom, FaceTime, 동영상, Spotify까지 모두.

### Windows의 라이브 캡션

```
Win + Ctrl + L
```

(또는 설정 → 접근성 → 캡션 → 라이브 캡션)

### Chrome의 라이브 캡션

```
chrome://settings/accessibility
```

→ "라이브 캡션" 켜기. Chrome 안에서 재생되는 모든 영상·오디오에 적용됩니다.

## 3. Otter.ai (회의 녹음 + 자막)

영어 회의에 가장 인기 있는 도구입니다.

```
otter.ai
```

- 무료: 월 600분
- 유료: 무제한 + 화자 구분

회의 후 자막 + 요약까지 자동으로 정리해 줍니다.

## 4. 한국어 음성 → 자막 (Naver Clova Note)

```
clovanote.naver.com
```

- 한국어에 가장 정확
- 회의 녹음 → 화자별 자막
- 무료

## 5. 본인 영상에 자막 만들기 (jwidori 등록 시 도움)

본인이 만드신 영상을 jwidori 같은 자경단 갤러리에 올리실 때, 자막을 함께 올리시면 더 많은 분들이 보실 수 있어요.

### 무료 도구

- **YouTube Studio** — 영상 업로드 후 자동 자막 생성 → 다운로드
- **CapCut** — 자동 자막 + 편집
- **Subtitle Edit** (Windows) — 무료 오픈소스, 정밀 편집

### 자막 파일 형식

- `.srt` — 가장 일반적, 메모장에서 편집 가능
- `.vtt` — 웹 표준
- `.ass` — 색·위치 등 풍부한 표현

## 6. 자막 활용 학습 팁

### 영어 학습에

- 1단계: 한국어 자막으로 보기
- 2단계: 영어 자막으로 보기 (천천히)
- 3단계: 자막 끄고 듣기

영상 한 편을 3번 보시면 영어 학습 효과가 매우 좋습니다.

### 코딩 강의에

- 자막을 켜시고 **재생 속도를 0.75배** 또는 **1.5배**로 조정 (본인에게 맞게)
- 어려운 부분은 자막을 멈추고 다시 보기
- 자막을 텍스트로 복사해서 노트에 붙여넣기 (학습 자료로 보관)

## 7. 시각·청각 동시 접근성

저시력 + 청각 장애가 있으시면.

- 점자 디스플레이 + 자막 결합
- macOS의 라이브 자막 + VoiceOver 동시 사용
- 큰 글자 자막 + 강한 진동 알림

본인 환경에 맞는 조합은 본인이 가장 잘 아십니다. 자경단원과 함께 시도해 보시면서 정리해 가시면 좋아요.
