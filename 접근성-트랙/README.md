## 학습 원칙

- **본인 방식이 우선입니다.** "정상" 코딩 환경이라는 건 없다고 봅니다.
- **속도를 강요하지 않습니다.** 챕터 하나가 한 달이어도 괜찮습니다.
- **본인 도구는 본인이 가장 잘 아십니다.** 멘토는 학습자에게 배우는 자세로 임합니다.

## 멘토 자경단원분들께

> [!TIP]
> GitHub은 스크린리더(VoiceOver/NVDA/내레이터)를 비교적 잘 지원합니다. 학습자가 처음이시면 [`GITHUB-GUIDE.md`](../GITHUB-GUIDE.md) §1~5(읽기·issue까지)부터 안내해 주세요. 키보드만으로 거의 모든 작업이 가능합니다.

- 본인이 잘 모르는 보조기기 사용자에게 "이렇게 해보세요"라고 권하시는 건 위험할 수 있습니다. 학습자의 워크플로우를 먼저 들어주세요.
- 접근성은 **새끼고양이의 권리**라고 봅니다. 시혜가 아닙니다 ([`MANIFESTO`](https://github.com/catguard-team/manifesto/blob/main/MANIFESTO.md)).
- 외부 자료는 한국어를 우선하지만, 영어가 더 풍부한 영역입니다. 양쪽 다 안내해 주세요.
