# 접근성 트랙 — 0장. 준비물 (본인의 보조기기 점검)

> 이 트랙은 본인 워크플로우가 우선입니다. 자경단의 안내는 참고일 뿐이에요.

이 챕터는 **20분**이면 끝납니다. 본인 페이스에 맞춰 가셔도 됩니다.

---

## 시작 전에

안녕하세요. 접근성 트랙은 다른 트랙과 좀 다릅니다. 다른 트랙에서는 자경단이 "이렇게 해보세요"라고 안내하지만, **이 트랙에서는 본인이 가장 잘 아십니다**. 자경단은 본인 워크플로우를 듣고 함께 정리하는 역할이에요.

오늘은 본인이 평소에 쓰시는 보조기기·도구를 점검하시고, 코딩이나 디지털 작업에 어떻게 활용하실지 큰 그림을 잡아봅니다.

---

## 1. 본인 워크플로우 정리

먼저 본인이 평소에 어떻게 컴퓨터·휴대폰을 쓰시는지 한 번 정리해 보시면 좋아요.

### 사용하시는 보조기기

| 영역 | 예시 | 본인 |
|------|------|------|
| 시각 | VoiceOver, NVDA, 내레이터, 돋보기 | _____ |
| 청각 | 자막, 시각 알림, 진동 | _____ |
| 운동 | 한 손 키보드, 음성 입력, 스위치 | _____ |
| 인지 | 단순 모드, 알림 줄이기, 일정 관리 | _____ |

빈 칸은 본인 도구를 적어주시면 됩니다.

### 평소에 잘 쓰시는 작업

- 글 쓰기 (문서·이메일)
- 인터넷 검색
- 영상·오디오 보기
- 코드 작성
- 사진·디자인 작업

본인이 가장 시간을 많이 쓰시는 작업이 무엇인지 한 번 떠올려 주세요.

## 2. 보조기기 점검

### 2-1. 화면 읽기 도구

| OS | 기본 도구 | 단축키 |
|----|----------|--------|
| macOS | VoiceOver | Cmd + F5 |
| Windows | 내레이터 | Win + Ctrl + Enter |
| iOS | VoiceOver | 설정 → 손쉬운 사용 |
| Android | TalkBack | 설정 → 접근성 |

처음 켜시면 어색하실 수 있는데, 끄시려면 같은 단축키를 다시 누르시면 됩니다.

### 2-2. 화면 확대 (저시력)

| OS | 도구 | 단축키 |
|----|------|--------|
| macOS | 확대/축소 | Option + Cmd + + |
| Windows | 돋보기 | Win + + |

### 2-3. 음성 입력 (운동·시각)

| OS | 도구 |
|----|------|
| macOS | Dictation (시스템 환경설정 → 키보드 → 받아쓰기) |
| Windows | 음성 입력 (Win + H) |
| iOS | 키보드의 마이크 아이콘 |

영어가 더 정확하고, 한국어도 점점 좋아지고 있습니다.

### 2-4. 한 손 키보드·외부 도구

본인이 쓰시는 도구가 있으시면 그대로 쓰시면 됩니다. 자경단에 등재된 도구는 [§11](https://github.com/catguard-team/manifesto/blob/main/OPERATIONS.md#11-자료-공유-절차-링크-등재) 절차로 추가될 수 있어요.

## 3. 코딩 작업에 보조기기 쓰는 사례

### VoiceOver + 코딩

VS Code, Xcode, GitHub 모두 VoiceOver와 함께 쓰실 수 있습니다. **CursorLess**, **Talon**, **VimSpeak** 같은 음성 코딩 도구도 있어요 (2장에서 다룹니다).

### 한 손 키보드 + 코딩

키보드 단축키 위주로 워크플로우를 짜시면 마우스를 거의 쓰지 않으셔도 됩니다. Vim, Neovim, Helix 같은 에디터가 키보드 친화적입니다.

### 단순 모드 (인지 접근성)

- VS Code의 "Zen Mode" — 모든 부수 UI를 숨김
- macOS의 "집중 모드" — 알림을 잠재움
- 한 번에 한 작업만 — 탭 1개, 창 1개

본인에게 맞는 환경을 본인이 가장 잘 아시니, 자유롭게 시도해 보세요.

## 4. 자경단원에게

이 트랙을 따라가시는 자경단원분들께. **학습자가 가장 잘 아십니다.** 자경단원은 다음 자세로 임해 주세요.

- 학습자의 워크플로우를 먼저 듣기
- "이렇게 해 보세요"가 아니라 "이런 방법도 있는데 어떠세요?" 식으로 제안
- 본인이 잘 모르는 도구는 같이 배우기
- 학습자의 페이스 존중 (한 챕터가 한 달 걸려도 OK)

접근성은 시혜가 아니라 **새끼고양이의 권리**입니다 (강령에서).
