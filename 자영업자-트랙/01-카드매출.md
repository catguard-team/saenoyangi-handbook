# 자영업자 트랙 — 1장. 카드매출 자료 한 번에 받기 (홈택스)

> 카드 단말기 회사마다 따로 받지 마시고, 홈택스에서 한 번에 받으시는 방법입니다.

이 챕터는 **20분**이면 끝납니다.

---

## 시작 전에

이지카드·KIS·신한·BC 등 카드사가 여러 개여서 매출 자료를 따로따로 받으시느라 번거로우셨죠? **홈택스에서 한 번에 통합으로 받으실 수 있습니다.** 부가세 신고할 때 정말 편해져요.

---

## 1. 홈택스 들어가기

브라우저 주소창에 정확히 입력해 주세요.

```
hometax.go.kr
```

> [!CAUTION]
> 검색 결과가 아니라 **주소창에 직접** 입력해 주세요. 가짜 사이트가 광고로 떠 있을 수 있습니다.

자물쇠(🔒) 표시와 "국세청 홈택스" 로고가 보이면 진짜입니다.

## 2. 로그인

오른쪽 위 **로그인** 버튼 클릭. 다음 중 편한 방법 선택.

| 방법 | 비고 |
|------|------|
| **간편 인증** | 추천. 카카오·네이버·PASS 앱으로 5초 인증 |
| **공동인증서** | 기존 사업자분들이 쓰시던 방법. 인증서 USB 필요 |
| **금융인증서** | 은행 앱 통해서 |

## 3. 사업용 신용카드 등록 (처음 한 번만)

처음이시면 본인 사업용 신용카드를 등록하셔야 매출·매입 자료가 자동으로 모입니다.

1. 메인 메뉴 → **조회/발급** → **현금영수증·전자세금계산서·계산서·신용카드** → **사업용 신용카드 등록**
2. 카드 번호 16자리 입력 → **등록**

여러 장이시면 모두 등록하시면 됩니다. 등록한 다음 날부터 매입 자료가 자동으로 잡혀요.

## 4. 카드매출 자료 받기 (이번 챕터의 핵심)

1. 메인 메뉴 → **조회/발급** → **현금영수증·전자세금계산서·계산서·신용카드** → **신용카드 매출자료 조회**
2. **조회 기간** 입력 — 예: 2026-01-01 ~ 2026-03-31 (1분기)
3. **조회** 버튼 클릭
4. 결과가 표로 뜹니다. 우상단의 **엑셀 다운로드** 버튼 클릭

엑셀 파일이 받아집니다. 카드사별 매출이 통합되어 있어요.

## 5. 받으신 파일 활용

엑셀 파일을 LibreOffice·엑셀로 열면 다음 정보가 들어 있습니다.

- 일자별 카드매출 합계
- 카드사별 매출 (BC, 삼성, 신한 등)
- 수수료 차감 후 정산 금액

부가세 신고 시 이 파일이 매우 편해요. 카드사마다 별도 자료를 정리하실 필요 없습니다.

## 6. 같은 메뉴에서 함께 받으시면 좋은 것

같은 화면 또는 인접 메뉴에서:

- **현금영수증 매출자료** — 현금 결제 매출
- **세금계산서 매입·매출** — 매입처 세금계산서

이 셋을 한 번에 받으시면 부가세 신고가 편해집니다. 세무사에게 보내실 때도 깔끔하게 정리되어요.

---

## 자주 막히시는 점

| 증상 | 해보실 것 |
|------|----------|
| 사업용 신용카드 등록이 안 돼요 | 본인 명의로 발급받은 카드인지 확인. 가족 카드는 등록 불가. |
| 매출이 안 잡혀요 | 등록 후 1~2일 기다려 주세요. 카드사 데이터가 국세청에 도착하는 시간이 있어요. |
| 엑셀 다운로드가 안 돼요 | 팝업 차단을 해제해 주세요 (브라우저 주소창 옆). 다른 브라우저에서 시도. |

---

## 안전 수칙

> [!CAUTION]
> 홈택스에서 본인 인증 후 **공용 컴퓨터**(가게 손님이 쓰시는 PC)에서는 반드시 로그아웃해 주세요. 본인의 사업 정보가 모두 노출됩니다.
>
> 의심스러운 "세무사 사칭" 전화·이메일이 많아요. 진짜 세무사는 본인이 계약한 분만 본인 자료를 보실 수 있습니다.
