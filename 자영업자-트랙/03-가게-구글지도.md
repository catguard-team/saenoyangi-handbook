# 자영업자 트랙 — 3장. 가게 구글지도 등록 (네이버 플레이스 + Google Business)

> 손님이 검색하실 때 본인 가게가 첫 페이지에 뜨도록 하는 가장 중요한 작업입니다.

이 챕터는 **40분**이면 끝납니다. 시간을 한 번 들이시면 오래갑니다.

---

## 시작 전에

요즘 손님은 식당·미용실·가게를 가실 때 거의 모두 **검색**부터 합니다. 본인 가게가 검색 결과에 안 뜨면 보이지 않는 가게가 됩니다.

해결법은 두 가지 사이트에 본인 가게를 등록하시는 거예요:
- **네이버 플레이스** (한국 손님)
- **Google Business** (외국 손님·구글지도 사용자)

둘 다 무료입니다.

---

## 1. 미리 준비하실 것

| 항목 | 비고 |
|------|------|
| 가게 정확한 주소 | 도로명 주소 |
| 영업 시간 | 요일별 |
| 전화번호 | 가게용 |
| 사진 5~10장 | 외관, 내부, 메뉴, 대표 메뉴, 주차장 |
| 사업자등록증 사본 | 사진 또는 PDF |
| 메뉴판 사진 | 가능하면 한 장에 정리 |

사진은 휴대폰으로 찍으셔도 충분합니다. 단 **밝은 시간에 가로 방향으로** 찍으시면 좋아요.

## 2. 네이버 플레이스 등록

### 2-1. 네이버 비즈니스 가입

1. 브라우저에서 `smartplace.naver.com` 입력
2. **무료 등록하기** 클릭
3. 네이버 아이디로 로그인

### 2-2. 정보 입력

순서대로 입력하시면 됩니다.

1. **업체명** — 가게 이름
2. **업종** — 음식점·미용실·카페 등
3. **주소** — 도로명으로 정확히
4. **전화번호** — 가게용
5. **영업시간** — 요일별
6. **사업자등록증** — 사진 또는 PDF 업로드

### 2-3. 사진 업로드

- 외관 1~2장
- 내부 1~2장
- 메뉴(또는 메뉴판) 1~2장
- 대표 음식·서비스 2~3장

### 2-4. 검토 대기

네이버에서 1~3일 정도 검토하고 승인됩니다. 승인되면 알림 메일이 옵니다.

## 3. Google Business 등록

### 3-1. Google 비즈니스 프로필 가입

1. 브라우저에서 `business.google.com` 입력
2. **지금 시작** 클릭
3. 구글 계정 로그인 (없으시면 만들기)

### 3-2. 정보 입력

네이버와 비슷합니다.

1. 업체명, 업종
2. **위치** — "주소가 있는 비즈니스" 선택 → 주소 입력
3. **서비스 지역** — 배달이 있으시면 추가
4. **연락처·웹사이트** — 가게 전화·SNS 링크

### 3-3. 본인 인증

구글에서 **엽서**를 본인 가게 주소로 보냅니다 (1~2주). 엽서에 적힌 코드를 비즈니스 프로필에 입력하시면 인증 완료.

> [!TIP]
> 일부 지역은 영상통화 인증도 가능합니다. 더 빠르게 인증할 수 있어요.

### 3-4. 사진 업로드

네이버와 같은 사진을 올리시면 됩니다.

## 4. 등록 후 — 손님 리뷰 받기

손님이 가게를 다녀가신 후에 **자연스럽게** 리뷰를 부탁드리세요.

### 좋은 방법

- 영수증에 "리뷰 한 줄 부탁드립니다" 손글씨
- 입구나 카운터에 작은 안내문 (강요 아닌 안내)
- 만족하신 손님께 직접 한 마디

### 피하시면 좋은 것

- 리뷰 강요 ("리뷰 안 쓰시면 ~" 식)
- 가짜 리뷰 만들기 (적발되면 계정 정지)
- 리뷰 대가로 할인 (네이버·구글 정책 위반)

## 5. 정보 최신 유지하기

영업시간이 바뀌거나, 메뉴가 바뀌거나, 임시 휴무가 있으면 **즉시** 업데이트하세요.

손님이 와서 닫혀 있으면 가장 안 좋은 인상이 됩니다. 5분 들이시면 되는 일입니다.

---

## 안전 수칙

> [!CAUTION]
> "네이버 검색 1위 보장 마케팅" 같은 영업 전화·이메일이 많습니다. 대부분 사기이거나 효과 없는 광고입니다. **본인이 직접 등록**하시고 자연스럽게 운영하시는 게 가장 효과 있습니다.
>
> "사업자등록증 사본을 보내주시면 등록해드립니다"라고 하는 곳도 위험합니다. 본인 인증 정보가 새어나갈 수 있어요.

## 막히셨을 때

| 증상 | 해보실 것 |
|------|----------|
| 본인 인증 엽서가 안 와요 | 주소 정확한지 확인. 영상통화 인증으로 변경 가능. |
| 네이버 등록이 거절됐어요 | 사업자등록증·실제 영업 사진을 더 정확히 올려보세요. |
| 사진이 흐리게 나와요 | 휴대폰 카메라 청소. 밝은 낮에 다시 촬영. |
