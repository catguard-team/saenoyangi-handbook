## 학습 원칙

- **본업이 우선입니다.** 가게 닫고 컴퓨터 보는 시간이 없으시잖아요. 한 챕터는 영업 끝나고 30분 안에 끝나도록 짭니다.
- **무료 도구를 우선합니다.** 유료 툴은 본인이 결정하실 수 있도록 정보만 드리고, 자경단이 따로 추천하지는 않습니다 (다만 자경단원이 만든 유료 도구는 §12 지속가능성 정책에 따라 등재될 수 있습니다 — "유료" 라벨로 표시).
- **자동화 함정에 주의해 주세요.** 결제·송금 자동화는 만들지 않습니다 ([SAFETY](https://github.com/catguard-team/manifesto/blob/main/SAFETY.md)).
