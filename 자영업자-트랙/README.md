## 학습 원칙

- **본업이 우선.** 가게 닫고 컴퓨터 보는 시간이 없습니다. 한 챕터 = 영업 끝나고 30분.
- **무료 도구만.** 유료 툴은 본인이 결정. 자경단은 추천 안 합니다.
- **자동화 함정 주의.** 결제·송금 자동화는 만들지 않습니다 ([SAFETY](https://github.com/catguard-team/manifesto/blob/main/SAFETY.md)).

## 멘토 자경단원에게

> [!TIP]
> 사장님이 GitHub에 직접 등록할 일은 거의 없습니다. 자경단 자료를 읽기만 하면 OK. 본인이 자료 공유 차원에서 issue/PR 쓰고 싶을 때만 [`GITHUB-GUIDE`](../GITHUB-GUIDE.md) 안내.

- 사장님은 보통 **시간이 없습니다**. 30분짜리 강의 영상보다 5분짜리 GIF가 낫습니다.
- 본업 모르고 도구만 권하지 마세요. 미용실 사장님과 식당 사장님의 도구는 다릅니다.
