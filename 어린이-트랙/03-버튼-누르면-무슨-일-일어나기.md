# 어린이 트랙 — 3장. 버튼 누르면 무슨 일 일어나기

> 우리가 만든 화면이 사용자(친구·가족)와 대화하는 첫 걸음입니다.

이 챕터는 **30분**이면 끝납니다.

---

## 시작 전에

지금까지는 깃발(🚩)을 누르면 정해진 일이 일어났습니다. 오늘은 **사용자가 무언가를 했을 때** 컴퓨터가 반응하게 만들어 봅니다.

> "고양이를 클릭하면 색깔을 바꿔봐."

이런 식의 부탁이에요. "사용자가 X 했을 때, 너는 Y를 해줘." — 이게 컴퓨터 프로그램의 가장 기본적인 모양입니다.

---

## 1. 새 프로젝트 시작

스크래치에서 새 프로젝트를 시작하시거나, 1장에서 만든 프로젝트를 이어서 쓰셔도 됩니다.

## 2. 클릭 이벤트 블록

왼쪽 블록 목록에서 **이벤트** (노란색)를 클릭하세요. 그중 다음 블록을 끌어다 놓습니다.

```
🐱 이 스프라이트가 클릭되었을 때
```

이 블록은 "고양이가 클릭되면 아래 일을 해줘"라는 신호입니다.

## 3. 반응 블록 붙이기

그 아래에 보라색 **형태** 블록 중에서 다음을 붙입니다.

```
🐱 이 스프라이트가 클릭되었을 때
─────────────
다음 모양으로 바꾸기
```

스크래치 고양이는 두 가지 모양(다리 위치가 다른 두 컷)이 기본 들어 있어요. 클릭할 때마다 모양이 바뀝니다.

## 4. 눌러보기

코딩 영역이 아니라, **무대 화면의 고양이**를 직접 클릭해 보세요. 누를 때마다 고양이 다리가 움직입니다.

**축하드립니다.** 사용자가 우리 프로그램과 대화하기 시작했어요.

---

## 5. 더 풍성하게

`다음 모양으로 바꾸기` 외에도 여러 가지를 시도해 보세요.

| 추가 블록 | 어떤 일이 일어나나 |
|-----------|--------------|
| `0.5 초 동안 안녕! 라고 말하기` | 말풍선이 잠깐 떴다 사라짐 |
| `색깔 효과를 25 만큼 바꾸기` | 클릭할 때마다 색이 바뀜 |
| `90 도 돌기` | 고양이가 빙글빙글 돔 |
| `pop 소리 내기` (소리 블록) | 효과음이 남 |

블록을 여러 개 붙여서 한 번 클릭에 여러 일이 일어나게 하실 수도 있습니다.

> [!TIP]
> 블록을 위에서 아래로 순서대로 읽어주세요. 컴퓨터도 그 순서대로 일을 합니다.

## 6. 키보드도 받아보기

이벤트 블록 중에 `[스페이스] 키를 눌렀을 때`도 있습니다. 이걸 쓰시면 **키보드 입력**도 받을 수 있어요.

```
[스페이스] 키를 눌렀을 때
─────────────
야옹 소리 내기
```

스페이스 바를 누를 때마다 야옹 소리가 나는 프로그램입니다.

---

## 막히셨을 때

| 증상 | 해보실 것 |
|------|----------|
| 클릭해도 반응이 없어요 | 코딩 영역의 고양이가 아니라 **무대(오른쪽)**의 고양이를 클릭하셨나요? |
| 고양이 모양이 한 가지뿐이에요 | "모양" 탭을 눌러서 두 번째 모양이 있는지 확인하세요. |
| 소리가 안 나요 | 컴퓨터 음량이 켜져 있고, "소리" 탭에 효과음이 있는지 확인하세요. |
