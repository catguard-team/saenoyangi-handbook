# 어린이 트랙 — 1장. 첫 화면에 글자 띄우기

> 코딩의 첫 결과물입니다. 화면에 내가 쓴 글자가 나오는 순간을 만나봅니다.

이 챕터는 **20분**이면 끝납니다. 안 되면 30분. 30분 넘게 걸리면 디스코드 #도와줘로 한 줄 보내주세요.

---

## 시작 전에

안녕하세요. 컴퓨터에게 처음 일을 시켜보는 시간입니다. 어렵게 들리실 수 있는데, 사실은 컴퓨터가 우리 말을 잘 알아듣는 친구라고 생각하시면 편합니다.

오늘은 컴퓨터에게 이렇게 부탁할 거예요:

> "내가 쓴 글자, 화면에 보여줘."

이게 끝입니다. 한 줄짜리 부탁인데, 이게 모든 코딩의 시작입니다.

---

## 1. 스크래치 들어가기

[scratch.mit.edu](https://scratch.mit.edu)를 브라우저에서 열어주세요. 0장에서 회원가입을 하셨다면 로그인하시면 되고, 안 하셨어도 일단 시작은 가능합니다.

상단의 **"만들기"** 버튼을 눌러주세요.

> [!TIP]
> 화면이 영어로 보이면 오른쪽 위에 지구본 모양 아이콘에서 **한국어**를 선택하시면 됩니다.

## 2. 고양이 친구 찾기

화면 가운데에 **노란 고양이**가 있죠? 이 친구가 우리에게 일을 받아서 처리해 줄 분입니다.

고양이를 클릭해 보세요. 클릭하면 가운데에 선택 표시가 생깁니다.

## 3. 블록 두 개로 끝내기

왼쪽에 색깔별 블록들이 있는데요, 이렇게 골라주세요.

1. **노란색** 블록 묶음에서 → `🚩 클릭했을 때` 블록을 가운데 코딩 영역으로 끌어다 놓기
2. **보라색** 블록 묶음에서 → `안녕! 이라고 말하기` 블록을 그 아래에 붙이기

블록 두 개가 위아래로 연결되면 됩니다.

```
🚩 클릭했을 때
─────────────
안녕! 라고 말하기
```

## 4. 글자 바꿔보기

`안녕!`이라고 적힌 부분을 클릭하시면 다른 글자로 바꾸실 수 있습니다.

- "안녕, 나는 코딩 시작했어"
- "오늘은 무슨 요일이지?"
- "냐-옹!"

뭐든 좋습니다. 본인이 쓰고 싶은 한 줄.

> [!IMPORTANT]
> 본인 이름·학교·주소·전화번호는 적지 말아주세요. 다른 사람도 볼 수 있어요. 닉네임이나 가상의 이름이 좋습니다.

## 5. 눌러보기 — 결과 확인

화면 위쪽에 초록색 깃발(🚩) 아이콘이 보이실 거예요. 그걸 한 번 눌러보세요.

고양이가 본인이 쓴 글자를 말풍선으로 띄워줍니다.

**축하드립니다.** 컴퓨터에게 첫 일을 시키신 거예요.

---

## 막히셨을 때

| 증상 | 해보실 것 |
|------|----------|
| 블록이 연결이 안 돼요 | 블록을 살짝 위로 들어서 다른 블록 바로 아래에 붙여보세요. 자석처럼 붙습니다. |
| 깃발을 눌렀는데 아무 일도 없어요 | `🚩 클릭했을 때` 블록이 가장 위에 있는지 확인해 주세요. |
| 글자가 안 바뀌어요 | "안녕!" 부분을 한 번 더 클릭하시면 편집 상자가 뜹니다. |

위 셋 다 해봐도 안 되시면 디스코드 #도와줘 채널에 한 줄 보내주세요.

```
안녕하세요. 어린이 트랙 1장에서 [어떤 부분]에서 막혔어요.
스크린샷 한 장 같이 올립니다.
```
