# 어린이 트랙 — 5장. 내가 만든 거 친구한테 보여주기 (배포)

> 우리가 만든 작품을 인터넷에 올려서, 친구·가족이 링크 하나로 볼 수 있게 합니다.

이 챕터는 **20분**이면 끝납니다. 단, 보호자 동의 시간은 별도입니다.

---

## 시작 전에

지금까지 만드신 작품은 본인 컴퓨터(스크래치 화면)에만 있었어요. 오늘은 그걸 **인터넷에 공개**해서 다른 사람도 볼 수 있게 만들어봅니다.

> [!IMPORTANT]
> 이 챕터는 **공개**가 들어 있습니다. 미성년자분들은 진행 전에 보호자 동의를 꼭 받아주세요. 작성 동의와 공개 동의는 별개입니다 ([SAFETY-NOTES](../SAFETY-NOTES.md)).

---

## 1. 보호자에게 한 번 보여드리기

작품을 인터넷에 올리시기 전에, 보호자분께 한 번 보여드려 주세요. 같이 봐 주시면서 "이거 다른 사람들이 봐도 괜찮아?"를 함께 점검해 주시면 좋습니다.

체크할 것:

- 작품 안에 본인 이름·학교·집 주소·전화번호가 들어 있지 않은가
- 가족·친구의 식별 가능한 사진이 들어 있지 않은가
- 다른 사람이 봐서 부끄럽거나 곤란한 내용이 없는가

보호자가 OK 사인 주시면 다음 단계로 진행해 주세요.

## 2. 스크래치에 로그인

[scratch.mit.edu](https://scratch.mit.edu)에 회원가입을 안 하셨다면 이번에 가입하셔야 합니다.

> [!CAUTION]
> 회원가입 시 **본명·학교명·전화번호**를 닉네임으로 쓰지 말아주세요. `nyangi-2026` 같은 가상의 이름을 추천드립니다. 이메일은 보호자 이메일을 사용하시면 좋습니다.

## 3. 프로젝트 저장하기

작품을 만든 화면에서 **"파일 → 즉시 저장하기"**를 누르거나, 상단의 프로젝트 이름 옆 저장 표시를 확인하세요.

프로젝트 이름도 정해주세요. "내 첫 게임" 같은 단순한 이름이 좋습니다 (실명 금지).

## 4. 공유하기

화면 우상단에 **"공유하기"** 버튼이 있습니다 (오렌지색). 누르시면 프로젝트가 인터넷에 공개됩니다.

이제 누구든지 본인 프로젝트의 링크를 가지고 있으면 작품을 볼 수 있어요.

## 5. 링크 복사

프로젝트 페이지의 주소창(브라우저 위쪽)에 이런 모양의 링크가 있습니다:

```
https://scratch.mit.edu/projects/12345678/
```

이 링크를 복사하셔서 친구·가족에게 카톡으로 보내드리시면 됩니다.

**축하드립니다.** 처음 만든 작품을 세상에 공개하셨어요.

---

## 6. 친구가 본 후

친구가 작품을 봤다면 어떤 반응이 좋았는지 들어보세요. "더 재미있게 하려면 뭐가 필요할까?"를 같이 이야기하시면 다음 작품 아이디어가 나옵니다.

---

## 만약 마음에 안 드시면 — 비공개로 돌리기

언제든지 **"공유 취소"** 가능합니다. 프로젝트 페이지에서 다시 비공개로 돌릴 수 있어요. 이유는 묻지 않습니다.

```
프로젝트 페이지 → 우상단 → "공유 취소"
```
