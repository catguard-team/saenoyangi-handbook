# 어린이 트랙 — 0장. 준비물

> 코딩 시작 전에 필요한 것들. 비싼 거 없습니다. 다 무료.

이 챕터는 **30분**이면 끝납니다. 끝나면 1장으로.

---

## 1. 컴퓨터

다음 중 아무거나:

- 집에 있는 노트북·데스크톱 (Windows / Mac / 리눅스 다 OK)
- 학교에서 빌려주는 크롬북도 OK
- 스마트폰만 있는 경우 — 잠시 기다려주세요. 폰만 쓰는 트랙은 따로 만들고 있습니다.

**없어도 자경단은 도와줄 수 있습니다.** 디스코드 #도와줘 채널에 한 줄.

## 2. 인터넷

집 와이파이, 학교 와이파이, 어디든 OK. 영상 한 편 볼 수 있는 속도면 충분.

## 3. 브라우저 (이미 깔려 있을 가능성 99%)

- **크롬** 또는 **엣지** (Windows 기본) — 둘 다 OK
- **사파리** (Mac 기본) — OK
- 인터넷 익스플로러는 **금지**. 이미 사라진 골목입니다.

## 4. 코딩 친구 사이트

다음 중 하나만 골라서 회원가입. 처음에는 한 군데만.

| 사이트 | 좋은 점 | 시작하기 |
|--------|---------|----------|
| [scratch.mit.edu](https://scratch.mit.edu) | 글자 안 쓰고 블록만으로 코딩 | 회원가입 → "만들기" |
| [code.org](https://code.org/learn) | 게임 만들면서 배우기 | 그냥 시작하기 누르면 됨 |
| [엔트리 (한국)](https://playentry.org) | 한국어 + 학교에서 많이 씀 | 회원가입 → "만들기" |

> 이 트랙은 처음 1~3장은 **스크래치(또는 엔트리)** 로 진행. 이후에 글자로 코딩하는 챕터로 넘어갑니다.

## 5. 디스코드 (만 13세 이상만)

자경단은 [디스코드 #신참고양이](https://discord.gg/Dp4pKwns2Y) 채널에서 도와드립니다.

만 13세 미만이면 **보호자**가 옆에 있을 때만. 보호자가 디스코드 안 쓰는 경우 깃허브 issue로 질문해도 OK.

> [!TIP]
> GitHub 처음이면 [`GITHUB-GUIDE.md`](../GITHUB-GUIDE.md)를 보호자와 함께 읽어보세요. 회원가입·이슈 올리기·첫 PR까지 단계별 안내. 닉네임 정할 때 본명·학교·전화번호 넣지 않기 — [§2-2](../GITHUB-GUIDE.md#2-2-가입-단계).

## 6. 안 챙겨도 되는 것
