# 어린이 트랙 — 2장. 색깔과 도형 그리기

> 고양이가 펜이 되는 시간입니다. 화면에 직접 그림을 그려봅니다.

이 챕터는 **30분**이면 끝납니다.

---

## 시작 전에

1장에서 글자를 띄워보셨다면, 오늘은 **그림**을 그려볼 차례입니다. 컴퓨터에게 이렇게 부탁할 거예요:

> "고양이야, 펜 들고 네모 한 번 그려봐."

고양이가 펜을 들고 화면 위를 움직이면 자국이 남는데, 그 자국이 모여서 도형이 됩니다.

---

## 1. 펜 확장 기능 켜기

스크래치 화면 왼쪽 아래에 파란색 사각형 아이콘이 있습니다 (확장 기능). 클릭하시면 여러 카드가 뜨는데, 그중 **"펜"** 카드를 골라주세요.

이렇게 하시면 왼쪽 블록 목록에 새로운 **녹색** 블록들이 추가됩니다.

## 2. 시작 위치 정리하기

`🚩 클릭했을 때` 아래에 다음 블록들을 차례로 붙입니다.

```
🚩 클릭했을 때
─────────────
모두 지우기              ← 펜 (녹색)
펜 색깔을 [파란색]으로 정하기   ← 펜
x: 0, y: 0 으로 이동하기  ← 동작 (파란색)
펜 내리기                ← 펜
```

이 블록들은 "그리기 시작 전 깨끗하게 정리해 주세요"라는 부탁입니다.

## 3. 네모 그리기

이어서 다음 블록들을 붙입니다.

```
4 번 반복하기            ← 제어 (주황색)
   100 만큼 움직이기      ← 동작
   90 도 돌기             ← 동작
```

`반복하기` 블록 안에 `움직이기`와 `돌기`를 넣어주시면 됩니다 (블록이 ㄷ자 모양으로 감싸집니다).

이게 무슨 부탁인지 풀어보면:

> "100칸 앞으로 가서, 90도 돌고. 이걸 4번 반복해."

100칸 가서 90도 돌기를 4번 하면 — 네모가 그려집니다.

## 4. 깃발 눌러보기

🚩 깃발을 눌러보세요. 고양이가 화면을 움직이며 파란색 네모를 그립니다.

**축하드립니다.** 첫 도형을 그리셨어요.

---

## 5. 본인 도형 만들기

숫자를 바꿔서 다른 도형도 만들어 보세요.

| 도형 | 반복 횟수 | 한 번에 도는 각도 |
|------|----------|------|
| 삼각형 | 3 | 120 |
| 네모 | 4 | 90 |
| 오각형 | 5 | 72 |
| 육각형 | 6 | 60 |
| 동그라미 같은 거 | 360 | 1 |

> [!TIP]
> 도는 각도는 항상 `360 ÷ 반복 횟수`입니다. 한 바퀴(360도)를 N번에 나눠서 도는 거예요.

색깔도 바꿔 보세요. `펜 색깔을 [파란색]으로 정하기` 부분을 클릭하시면 색을 고르실 수 있습니다.

## 막히셨을 때

| 증상 | 해보실 것 |
|------|----------|
| 펜 블록이 안 보여요 | 1번 단계의 확장 기능을 다시 확인해 주세요. |
| 도형이 화면 밖으로 나가요 | `100 만큼 움직이기`의 100을 50이나 30으로 줄여보세요. |
| 네모가 비뚤어져요 | `90 도 돌기`가 맞는지 확인. 다른 숫자면 사각형이 안 됩니다. |
