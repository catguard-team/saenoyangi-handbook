# 어린이 트랙 — 4장. 숫자 알아맞히기 게임

> 컴퓨터가 정한 숫자를 친구가 맞히는 게임을 만들어봅니다. 첫 진짜 게임입니다.

이 챕터는 **40분**이면 끝납니다. 가장 어려운 챕터일 수 있습니다. 천천히 따라오시면 됩니다.

---

## 시작 전에

지금까지 우리는 컴퓨터에게 정해진 일을 시켰습니다. 오늘은 **컴퓨터가 직접 무언가를 정하고**, 사용자와 같이 게임을 하는 프로그램을 만들어봐요.

> "컴퓨터야, 1부터 100 사이에서 숫자 하나 골라. 친구한테 맞춰보라고 하고, 더 큰지 작은지 알려줘."

오늘 새로 배우는 것:
- **변수** — 컴퓨터가 무언가를 기억하는 상자
- **조건문** — "만약 ~이면, ~해" 식의 판단

---

## 1. 변수 만들기 (컴퓨터의 기억 상자)

왼쪽 블록 목록에서 **변수** (주황색)를 클릭하세요. **"변수 만들기"** 버튼이 보입니다.

이름을 `정답`으로 짓고 **확인**을 눌러주세요. 화면 왼쪽 위에 `정답: 0` 같은 게 뜹니다. 이게 우리 컴퓨터의 첫 기억 상자입니다.

## 2. 컴퓨터가 정답 정하기

```
🚩 클릭했을 때
─────────────
정답 을 [ 1 부터 100 사이의 난수 ] 로 정하기   ← 변수 + 연산
```

`난수` 블록은 **연산** 블록 묶음(녹색)에 있습니다. "난수"는 "랜덤한 숫자"라는 뜻이에요.

## 3. 사용자한테 물어보기

다음 블록을 이어 붙입니다.

```
[ 1부터 100 사이 숫자를 맞춰보세요 ] 라고 묻고 기다리기   ← 감지 (하늘색)
```

`묻고 기다리기` 블록은 **감지** 묶음에 있습니다. 사용자가 답을 입력할 때까지 기다려요.

사용자가 입력한 답은 자동으로 `대답`이라는 변수에 저장됩니다 (감지 묶음에 있음).

## 4. 답 비교하기 — 조건문

```
만약 < 대답 = 정답 > 이라면        ← 제어 + 연산
   [ 정답입니다! ] 라고 말하기      ← 형태
아니면
   만약 < 대답 < 정답 > 이라면
      [ 더 큰 숫자입니다 ] 라고 말하기
   아니면
      [ 더 작은 숫자입니다 ] 라고 말하기
```

이 블록 묶음을 만들기가 좀 어려워 보일 수 있는데, 아래에서 위로 끼워 넣으시면 편합니다.

> [!TIP]
> `만약 ~ 아니면` 블록은 **제어** 묶음(주황색)에 있어요. ㄷ자 모양 안에 다른 블록을 끼워 넣을 수 있습니다.

## 5. 깃발 누르기 — 게임 시작

🚩 깃발을 누르시면 게임이 시작됩니다. 무대에서 답을 입력하시면 고양이가 정답인지 더 큰지 작은지 알려줍니다.

**축하드립니다.** 첫 게임을 만드셨어요.

---

## 6. 게임 더 똑똑하게

지금은 한 번 답하면 끝입니다. 정답 맞힐 때까지 계속 물어보게 하시려면 `반복하기` 블록을 사용하세요.

```
🚩 클릭했을 때
정답 을 [ 1 부터 100 사이의 난수 ] 로 정하기

[ 대답 = 정답 ] 까지 반복하기      ← 제어 (~까지 반복)
   [ 1부터 100 사이 숫자 ] 라고 묻고 기다리기
   만약 < 대답 < 정답 > 이라면
      [ 더 큰 숫자입니다 ] 라고 말하기
   아니면
      [ 더 작은 숫자입니다 ] 라고 말하기

[ 정답입니다! ] 라고 말하기
```

이렇게 만드시면 정답을 맞힐 때까지 계속 물어봅니다.

---

## 막히셨을 때

| 증상 | 해보실 것 |
|------|----------|
| 정답이 항상 0이에요 | "변수" 묶음에서 변수를 제대로 만들었는지 확인. |
| 만약 블록 안에 비교가 안 들어가요 | 비교 블록(`= < >`)을 만약 블록의 다이아몬드 자리에 정확히 끼워야 합니다. |
| 너무 빠르게 끝나요 | "반복하기"로 감싸지 않으셨을 수 있어요. 6번 단계 다시 확인. |
