# 어린이 트랙 — 6장. 첫 쥐돌이 자랑하기 (jwidori 등록)

> 자경단의 첫 쥐돌이 갤러리에 본인 작품을 등록합니다. 어린이 트랙 마지막 챕터입니다.

이 챕터는 **30분**이면 끝납니다. 보호자와 함께 진행해 주세요.

---

## 시작 전에

자경단에는 [**jwidori**](https://github.com/catguard-team/jwidori)라는 갤러리가 있습니다. **새끼고양이가 잡은 첫 작품**들을 모아두는 곳이에요.

5장에서 작품을 친구·가족에게 공유해 보셨다면, 오늘은 한 걸음 더 나가서 **자경단 골목 전체**에 자랑해 봅니다.

> [!IMPORTANT]
> jwidori는 GitHub에 있는 공개 갤러리입니다. 미성년자분은 **보호자가 옆에 계신 자리에서** 진행해 주세요. 보호자 동의도 필수입니다 ([SAFETY-NOTES](../SAFETY-NOTES.md)).

---

## 1. 보호자와 함께 한 번 더 점검

본인 작품이 다음 조건을 모두 만족하시는지 확인해 주세요.

- [ ] 본인 이름·학교·주소·전화번호가 작품에 없습니다
- [ ] 가족·친구의 식별 가능한 사진이 없습니다
- [ ] 다른 사람을 비웃거나 따돌리는 내용이 없습니다
- [ ] 5장에서 스크래치 "공유하기"를 누르셔서 링크를 가지고 계십니다

보호자가 모두 ✅ 사인 주시면 진행해 주세요.

## 2. GitHub 처음이시면

GitHub은 자경단 문서가 살고 있는 곳입니다. 처음 쓰시면 [GITHUB-GUIDE](../GITHUB-GUIDE.md) 1장~5장을 보호자와 함께 한 번 보시면 좋습니다.

> [!TIP]
> 본인이 GitHub 가입을 안 하셔도 됩니다. **보호자**가 가입하셔서 대신 등록하셔도 OK입니다. 이게 가장 안전한 방법이에요.

## 3. jwidori에 등록 요청 issue 올리기

[jwidori 새 이슈 만들기](https://github.com/catguard-team/jwidori/issues/new)에 들어가세요.

제목과 내용에 다음 정보를 적어주시면 됩니다:

```markdown
제목: [어린이 트랙] 내 첫 게임 — nyangi-2026

내용:

- **작품 이름**: 내 첫 게임 (또는 본인이 정한 이름)
- **트랙·챕터**: 어린이 트랙, 4장 숫자 알아맞히기에서 잡은 쥐돌이
- **링크**: https://scratch.mit.edu/projects/12345678/
- **사용한 도구**: 스크래치
- **닉네임**: nyangi-2026 (본명 아님)
- **소개 한 줄**: 1부터 100 사이 숫자를 맞히는 게임을 만들었어요.

보호자 동의 받았습니다. ✅
```

> [!CAUTION]
> 본명·학교·전화번호·집 주소를 절대 적지 마세요. 이건 GitHub 공개 페이지라 누구나 봅니다. 닉네임만으로 충분합니다.

## 4. 자경단원의 답변 기다리기

보통 24~72시간 안에 자경단원이 답글을 달아드립니다.

- 위험 7가지(어린이 안전, 노인 사기, 자해 조장, 차별·혐오, 민감정보, 저작권, 명예훼손) 검증을 통과하시면
- jwidori 갤러리에 본인 작품 페이지가 생기고
- 디스코드 #공지에 짧게 알려드립니다

## 5. 첫 쥐돌이 인증 받기

등록이 완료되면, 본인 스크래치 프로젝트에 자경단 검증 배지를 붙이실 수 있습니다.

```markdown
[![자경단 검증](https://catguard-team.github.io/badges/verified.svg)](https://github.com/catguard-team/jwidori)
```

이 마크다운을 프로젝트 설명에 넣으시면 됩니다.

**축하드립니다.** 첫 쥐돌이 사냥 완료입니다. 행동강(綱)냥(領) 8조 — *첫 쥐돌이를 부끄러워하지 않습니다.* 그대로 실현하셨어요.
