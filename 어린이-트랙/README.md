## 학습 원칙

- **결과물 먼저, 이론 나중에.** 첫 챕터에 화면에 무언가 나오게 만듭니다.
- **틀려도 괜찮.** 빨간 글씨(에러)는 적이 아니라 사냥감입니다.
- **30분 안에 끝나는 챕터.** 안 끝나면 챕터를 더 작게 쪼갭니다.
