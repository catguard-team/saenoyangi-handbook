# 노묘 트랙 — 컴퓨터를 처음 켜시는 어르신용

> 그동안 휴대폰만 쓰셨던 분, 키오스크 앞에서 막막하셨던 분, "유튜브는 보는데 글 쓰는 건 어떻게 하지?" 싶으신 분.

안녕하세요. 자경단은 노묘분들을 부끄러워하지 않습니다. 골목의 어르신은 저희 모두의 어르신이라고 생각합니다.

## 학습 원칙

- **한 번에 한 가지만.** 챕터 하나에 30분 이상 안 걸리도록 해주세요.
- **무서워하지 않으셔도 됩니다.** 컴퓨터는 거의 부서지지 않습니다.
- **모르는 단어는 바로 물어보세요.** "문서 읽으세요(RTFM)"라는 응답을 받으시면 알려주세요.

## 멘토 자경단원분들께

> [!TIP]
> 어르신이 GitHub 자체에 가입하실 필요는 없습니다 (읽기는 회원가입 없이도 가능합니다). 본인이 issue로 질문을 남기고 싶으실 때만 [`GITHUB-GUIDE §2~3`](../GITHUB-GUIDE.md#2-회원가입)을 따라 가입하시면 됩니다. SMS 2FA를 권장드립니다.

- 어르신과는 **화면 공유 통화**가 가장 효율적입니다. 카카오톡 영상통화 화면공유 + 음성 안내가 잘 통합니다.
- 단계마다 사진을 찍어드리시면 좋습니다. 글로 적힌 절차는 어르신께 어려운 경우가 많습니다.
- "이거 누르세요"보다 "여기 파란 네모 보이시죠? 거기 누르시면 돼요"가 더 잘 통합니다.
