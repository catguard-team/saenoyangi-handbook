# 노묘 트랙 — 컴퓨터 처음 켜는 어르신용

> 폰만 쓰셨던 분, 키오스크 앞에서 막막했던 분, "유튜브는 보는데 글 쓰는 건 어떻게 하지?" 싶은 분.

자경단은 노묘를 부끄러워하지 않습니다. 골목의 어르신은 우리 모두의 어르신입니다.

| 챕터 | 제목 | 상태 |

## 학습 원칙

- **한 번에 한 가지만.** 챕터 하나에 30분 이상 안 걸리도록.
- **무서워하지 않기.** 컴퓨터는 부서지지 않습니다. 거의.
- **모르는 단어는 바로 물어보기.** RTFM 받으면 신고하세요.

## 멘토에게

> [!TIP]
> 어르신이 GitHub 자체에 등록할 필요는 없습니다(읽기는 회원가입 없이도 가능). 본인이 issue로 질문 남기고 싶을 때만 [`GITHUB-GUIDE §2~3`](../GITHUB-GUIDE.md#2-회원가입) 따라 가입하면 됩니다. SMS 2FA 권장.

- 어르신과는 **화면 공유 통화**가 가장 효율적. 카카오톡 영상통화 화면공유 + 음성 안내.
- 단계마다 사진 찍어드리세요. 글로 적힌 절차는 어르신에게 어려운 경우가 많습니다.
- "이거 누르세요" 보다 "여기 파란 네모 보이시죠? 거기 누르시면 돼요"
