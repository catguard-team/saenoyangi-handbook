# 노묘 트랙 — 4장. 글자 키워서 보기

> 화면 글자가 작아 답답하실 때, 큰 글자로 편하게 보시는 방법입니다.

이 챕터는 **15분**이면 끝납니다.

---

## 시작 전에

화면 글자가 너무 작아서 눈이 피곤하시죠? 안경 도수를 올리시기 전에 **컴퓨터에서 글자를 크게** 만드시면 훨씬 편해집니다. 아래 세 가지 방법을 차례로 알려드릴게요.

---

## 1. 한 번만 크게 — 인터넷 화면

지금 보시는 인터넷 화면만 잠깐 크게 만들고 싶으실 때.

### Windows·Mac 둘 다

키보드에서 두 개를 동시에 눌러주세요.

| 효과 | Windows | Mac |
|------|---------|-----|
| 크게 | **Ctrl 키 + +** | **Cmd 키 + +** |
| 작게 | **Ctrl 키 + -** | **Cmd 키 + -** |
| 원래대로 | **Ctrl 키 + 0** | **Cmd 키 + 0** |

`+`는 사실 `=` 키 위에 같이 적혀 있는 그 키입니다 (Shift 누르고 = = 누르시는 거예요).

> [!TIP]
> 이 방법은 **그 사이트만** 커집니다. 다른 사이트에 가시면 다시 작아져요. 매번 누르시기 번거로우면 다음 방법으로.

## 2. 컴퓨터 전체 — 시스템 설정 (오래가는 방법)

### Windows의 경우

1. 시작 메뉴(⊞) 클릭
2. **설정** 톱니바퀴 아이콘 클릭
3. **접근성** 또는 **시스템 → 디스플레이** 선택
4. **텍스트 크기** 슬라이더를 오른쪽으로 (글자가 미리보기에서 커집니다)
5. **적용** 누르기

### Mac의 경우

1. 사과 아이콘(🍎) → **시스템 환경설정** (또는 **시스템 설정**)
2. **손쉬운 사용** 또는 **디스플레이** 클릭
3. **확대/축소** 또는 **디스플레이 크기** 조절

## 3. 마우스 휠로 키우기 (Ctrl 누른 채로)

키보드의 **Ctrl 키**를 누른 채로 마우스 휠(가운데 굴림판)을 위로 굴리시면 화면이 커집니다. 아래로 굴리시면 작아져요.

이 방법은 인터넷·문서·사진 등 **거의 모든 곳에서** 작동합니다.

## 4. 돋보기 기능 (한 부분만 크게)

부분만 크게 보고 싶으시면.

### Windows의 돋보기

- 켜기: **윈도우 키(⊞) + +**
- 끄기: **윈도우 키 + Esc**

화면에 작은 돋보기 창이 떠서, 마우스가 가는 곳을 크게 보여줍니다.

### Mac의 돋보기

1. 시스템 환경설정 → 손쉬운 사용 → **확대/축소**
2. **확대/축소 사용** 켜기
3. **Option + Cmd + =** 로 확대, **Option + Cmd + -** 로 축소

---

## 5. 색깔도 편하게 — 다크 모드

검은 배경에 하얀 글씨가 더 편하시면 **다크 모드**를 써 보세요. 눈이 덜 피곤해요.

### Windows

설정 → 개인 설정 → 색 → **모드 선택: 다크**

### Mac

시스템 환경설정 → 일반 → **모양: 다크**

---

## 막히셨을 때

| 증상 | 해보실 것 |
|------|----------|
| Ctrl + +를 눌러도 안 커져요 | 인터넷 브라우저 창이 켜져 있는지 확인. 메모장이나 다른 프로그램에서는 다른 키를 사용해야 할 수 있어요. |
| 너무 커서 화면이 잘려 보여요 | Ctrl + 0 (원래대로) 눌러주세요. 그 후 천천히 한 단계씩 키워보세요. |
| 키보드의 + 키가 어디 있는지 모르겠어요 | 숫자 0 옆에 = 키가 있고, Shift 누르신 채로 = 누르시면 +가 됩니다. |
