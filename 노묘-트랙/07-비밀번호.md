# 노묘 트랙 — 7장. 안전하게 비밀번호 만들기

> 본인 계정을 지키는 가장 기본적이고 중요한 일입니다.

이 챕터는 **20분**이면 끝납니다.

---

## 시작 전에

요즘 사기와 해킹이 많이 일어납니다. 본인 계정을 지키는 가장 기본은 **좋은 비밀번호**예요. 어렵게 들리시지만, 사실은 몇 가지 원칙만 지키시면 됩니다.

---

## 1. 좋은 비밀번호의 조건

| 좋음 ✅ | 나쁨 ❌ |
|--------|--------|
| 12자 이상 | 8자 이하 |
| 영어·숫자·특수문자 섞기 | 숫자만, 영어만 |
| 본인과 관계없는 단어 | 본인 이름·생일·전화번호 |
| 사이트마다 다른 비밀번호 | 모든 사이트에 같은 비밀번호 |

## 2. 좋은 비밀번호 만드는 법

### 방법 1 — 좋아하시는 문장에서

본인이 좋아하시는 문장이나 노래 가사를 떠올려 주세요.

예: "오늘은 비가 와서 밥을 두 그릇 먹었다"

이 문장의 첫 글자만 따고, 숫자와 특수문자를 섞으시면:

```
oNbgwBe2GMd!
```

(o늘N비g와w밥e두2G그릇M먹다d!)

이런 식으로 만드시면 본인은 외우기 쉽고 다른 사람은 추측하기 어려운 비밀번호가 됩니다.

### 방법 2 — 비밀번호 관리 도구 (더 편함)

좋은 비밀번호를 만들고 외우는 일이 어려우시면, **비밀번호 관리 도구**가 이 일을 대신 해줍니다.

| 도구 | 비고 |
|------|------|
| 1Password | 유료, 가장 안전. 가족 요금제 추천 |
| Bitwarden | 무료 + 유료 옵션. 한국어 지원 |
| 브라우저 저장 (Chrome/Edge/Safari) | 가장 쉬움. 단 컴퓨터에 다른 사람이 들어오시면 노출 가능 |

> [!TIP]
> 비밀번호 도구가 어려우시면 **종이 노트에 적어두시는 것**도 괜찮은 방법입니다 (안전한 곳에 보관). 다만 사진은 찍지 마세요.

## 3. 절대 하지 마실 것

### ❌ 본인 정보로 만들기

- 본명, 생일, 전화번호 끝자리
- 가족 이름, 강아지 이름
- "1234", "qwerty", "password", "abcd"

### ❌ 모든 사이트에 같은 비밀번호

한 사이트가 해킹당하면 **모든 사이트**가 위험해집니다.

### ❌ 다른 사람에게 알려주기

- 자녀가 도와드린다고 하셔도, 비밀번호는 본인만 아셔야 합니다 (자녀가 대신 들어가셔야 한다면 그때그때 함께 입력)
- 전화로 비밀번호를 묻는 사람은 100% 사기입니다
- 카톡·문자로 비밀번호를 묻는 곳도 마찬가지

### ❌ 컴퓨터 메모장에 그대로 적기

컴퓨터에 비밀번호 파일을 만드시는 건 위험해요. 위 방법 1, 2를 써주세요.

## 4. 2단계 인증 (꼭 켜주세요)

비밀번호 외에 한 번 더 본인 인증을 하는 것을 **2단계 인증** (또는 2FA)이라고 합니다.

비밀번호가 들켜도 본인 휴대폰까지 같이 있어야 들어갈 수 있어서, 훨씬 안전해집니다.

### 켜시면 좋은 곳

- 카카오톡 — 설정 → 개인 정보 보호 → 2단계 인증
- 네이버 — 내 정보 → 보안 → 2단계 인증
- 구글 — 계정 → 보안 → 2단계 인증
- 은행 앱 — 보통 기본으로 켜져 있음
- 정부24 — 본인 인증을 매번 받으므로 별도 설정 불필요

방법은 사이트마다 약간 다른데, 보통 **휴대폰으로 6자리 숫자**를 받으셔서 입력하시는 식이에요.

## 5. 비밀번호를 잊으셨을 때

당황하지 마세요. **"비밀번호 찾기"** 버튼이 거의 모든 사이트에 있습니다.

1. 로그인 화면에서 **비밀번호를 잊으셨나요?** 링크 클릭
2. 본인 이메일이나 휴대폰으로 인증 코드 받기
3. 새 비밀번호 만들기

새로 만드시는 김에 위 1번의 좋은 비밀번호 조건을 지켜서 만드시면 됩니다.

---

## 자녀·자경단원에게 부탁드릴 것

직접 하시기 어려우시면, 자녀나 자경단원에게 **함께 앉아서** 도움을 부탁드리세요. 단:

- 비밀번호는 본인이 직접 입력 (자녀가 대신 누르지 마시고 옆에서 안내만)
- 비밀번호를 자녀에게 말로 알려주지 마세요 (종이에 본인이 직접 쓰시고 보관)

## 막히셨을 때

| 증상 | 해보실 것 |
|------|----------|
| 비밀번호가 너무 어려워서 못 외우겠어요 | 비밀번호 관리 도구를 써보시거나, 종이 노트에 적어두세요. |
| 어떤 사이트에서 어떤 비밀번호인지 모르겠어요 | 사이트마다 "비밀번호 찾기"로 새로 만드시고, 이번엔 종이 노트에 정리해 두세요. |
| 2단계 인증을 켰는데 휴대폰을 잃어버렸어요 | 사이트별 "백업 코드"를 미리 받아두시는 게 좋아요. 자경단 디스코드 #도와줘에 도움 요청. |
