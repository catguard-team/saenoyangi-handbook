# 노묘 트랙 — 2장. 마우스와 키보드 익숙해지기

> 컴퓨터에서 손과 손가락처럼 쓰는 도구입니다. 천천히 한 번씩 눌러보시면 익숙해지세요.

이 챕터는 **30분**이면 끝납니다. 너무 빨리 가실 필요 없습니다.

---

## 시작 전에

마우스는 컴퓨터의 **손**입니다. 키보드는 컴퓨터에 글자를 알려주는 **목소리**라고 생각하시면 됩니다. 둘 다 처음 잡으시면 어색하지만, 며칠만 쓰시면 자연스러워져요.

---

## 1. 마우스 잡기

손바닥을 마우스 위에 살짝 얹으시면 됩니다. **꽉 쥐지 마세요** — 손목이 아파요.

- 검지손가락 → 왼쪽 버튼 위
- 중지손가락 → 오른쪽 버튼 위
- 가운데 굴리는 바퀴 → 검지·중지 사이

## 2. 화면에서 화살표 움직이기

마우스를 책상 위에서 옆으로 살짝 미시면, 화면의 **흰 화살표**가 같은 방향으로 움직입니다. 이 화살표를 **커서**라고 불러요.

연습:
- 마우스를 오른쪽으로 → 화살표도 오른쪽으로
- 마우스를 위로 → 화살표도 위로
- 화면 끝까지 가시면 마우스를 들어서 책상 가운데로 옮기시면 됩니다 (마우스를 들면 화살표는 안 움직여요)

## 3. 한 번 클릭 (그냥 클릭)

화면의 어떤 그림이나 글자에 화살표를 갖다 댄 후, **마우스 왼쪽 버튼을 한 번 살짝 눌렀다 떼세요.** 이게 "클릭"입니다.

연습할 곳: 바탕화면 아래쪽의 **시작 메뉴 아이콘**(윈도우는 ⊞, 맥은 🍎)에 화살표를 가져가서 클릭해 보세요. 메뉴가 뜨면 됩니다.

## 4. 두 번 클릭 (더블 클릭)

같은 자리를 **빠르게 두 번** 누르는 것이 더블 클릭입니다. 손가락이 좀 빨라야 해요.

연습할 곳: 바탕화면의 휴지통 아이콘을 더블 클릭하시면 휴지통 안이 열립니다.

> [!TIP]
> 손가락이 떨리거나 두 번 누르기 어려우시면, **마우스 설정**에서 더블 클릭 속도를 느리게 바꾸실 수 있습니다. 자녀나 자경단원에게 부탁드리시면 도와드립니다.

## 5. 오른쪽 버튼 클릭

마우스의 **오른쪽 버튼**을 한 번 누르시면, 작은 메뉴가 뜹니다. "이 자리에서 무엇을 하실 수 있는지" 메뉴를 보여주는 거예요.

연습: 바탕화면의 빈 자리에서 오른쪽 버튼을 한 번 클릭해 보세요. 작은 메뉴가 뜨면 됩니다. 메뉴를 닫으시려면 다른 곳을 한 번 (왼쪽으로) 클릭하시면 됩니다.

## 6. 키보드 — 글자 쓰기

키보드에서 글자가 적힌 키를 누르시면 그 글자가 화면에 입력됩니다. 메모장을 열어서 한 번 써 보시면 좋아요.

### 메모장 열기 (Windows)

1. 시작 메뉴(⊞) 클릭
2. 키보드로 `메모장`이라고 치기
3. 검색 결과의 **메모장** 클릭

### 메모장 열기 (Mac)

1. 화면 우상단 돋보기(🔍) 클릭
2. `텍스트 편집기`라고 치기
3. **텍스트 편집기** 클릭

메모장이 열리면 키보드로 자유롭게 글자를 쳐 보세요.

## 7. 한국어와 영어 바꾸기

처음에는 영어로 쳐질 수 있습니다. 한국어로 바꾸시려면:

| 컴퓨터 | 한영 전환 키 |
|--------|------------|
| Windows 한국어 키보드 | **한/영** 키 (스페이스바 오른쪽) |
| Mac | **Ctrl + Space** 또는 **Caps Lock** |

한 번씩 눌러보시면서 영어 한국어가 바뀌는 걸 확인해 주세요.

## 8. 백스페이스 — 지우기

키보드 오른쪽 위의 **Backspace** 키 (긴 화살표 ⌫)는 글자를 지웁니다. 한 번 누를 때마다 글자 하나씩 지워져요.

오타가 나도 부담 없이 지우시면 됩니다.

---

## 막히셨을 때

| 증상 | 해보실 것 |
|------|----------|
| 더블 클릭이 안 돼요 | 1, 2초 사이에 빠르게 두 번. 안 되시면 마우스 설정에서 속도 늦추기. |
| 키보드 누른 글자가 다른 게 나와요 | 한/영 전환이 잘못 됐을 수 있어요. 7번 확인. |
| 화면이 옆으로 떠 있어요 | 실수로 화면 회전을 누르셨을 수 있어요. **Ctrl + Alt + ↑(위 화살표)**를 눌러보세요 (Windows). |
