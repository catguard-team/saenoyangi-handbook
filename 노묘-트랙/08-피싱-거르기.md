# 노묘 트랙 — 8장. 의심 메일·문자 거르기 (보이스피싱·스미싱)

> 사기 메시지를 알아보고 안전하게 넘기시는 법입니다. 노묘 트랙의 마지막 챕터예요.

이 챕터는 **30분**이면 끝납니다. 천천히 읽어주세요.

---

## 시작 전에

지금 어르신·어린이를 대상으로 한 사기가 정말 많습니다. 한 번 당하시면 큰 돈을 잃으실 수 있어요. 다행히 대부분의 사기는 **몇 가지 신호**로 알아보실 수 있습니다.

오늘 익히실 단 하나의 원칙:

> **급한 것 같이 느껴지면, 그게 사기입니다.**

진짜 정부·은행은 절대 "지금 당장 입금하지 않으면 큰일 난다"라고 하지 않습니다.

---

## 1. 흔한 사기 유형

### ❌ 보이스피싱 (전화로)

```
"여기는 검찰청입니다. ○○○씨, 본인 명의로 사건이 접수됐습니다.
지금 바로 안전계좌로 돈을 옮기지 않으시면 구속됩니다."
```

진짜 검찰·경찰은:
- 전화로 돈을 요구하지 않습니다
- "안전계좌"라는 건 존재하지 않습니다
- 구속하기 전에 정식 절차가 있습니다 (법원 출석 통지서 등)

**대처**: 일단 끊으세요. 정말 검찰에서 연락한 게 맞는지 궁금하시면 1301(검찰청 대표번호)에 직접 거셔서 확인하세요.

### ❌ 스미싱 (문자·카톡으로)

```
"[택배] 주소 미상. 아래 링크에서 확인해 주세요.
http://kakao-pay.suspicious-link.com"
```

```
"[국민건강보험공단] 환급금이 있습니다.
조회: bit.ly/xxxxx"
```

진짜 기관의 메시지는:
- 짧은 링크(`bit.ly`, `goo.gl`)를 거의 쓰지 않습니다
- 이상한 도메인(`.com.co`, `kakao-xxx.net`)을 쓰지 않습니다
- 갑자기 큰 환급금이 있다고 하지 않습니다

**대처**: 링크를 **절대 누르지 마세요**. 그 기관에 직접 전화로 확인하세요.

### ❌ 자녀 사칭 (가장 무서운 사기)

```
"엄마, 나 폰 액정 깨졌어. 친구 폰으로 보내. 급한 일인데 돈 좀 보내줘.
계좌: ○○은행 123-456-789"
```

**진짜 자녀라면 어떻게 확인할까요?**

- 자녀에게 **직접 전화**를 거셔보세요. 진짜면 받습니다.
- "방금 메시지 보냈니?"라고 물어보시거나
- 자녀만 아는 옛날 일을 물어보세요 ("어렸을 때 키웠던 강아지 이름이 뭐야?")

**돈은 절대 먼저 보내지 마세요.** 진짜 자녀라면 기다려 줍니다.

## 2. 안전 신호 5가지

다음 중 하나라도 보이면 **사기일 가능성이 큽니다.**

1. **시간 압박** — "지금 당장", "5분 안에", "오늘 안에"
2. **돈 요구** — 환급, 안전계좌, 송금, 가상화폐, 상품권
3. **위협** — 구속, 신용불량, 압류, 자녀 사고
4. **이상한 링크** — 짧은 링크, 처음 보는 도메인
5. **개인정보 요구** — 비밀번호, 인증번호, 주민등록번호 끝자리

## 3. 안전한 행동 5가지

1. **일단 끊거나 닫기** — 답하지 않으셔도 손해 없습니다
2. **주변 사람에게 보여주기** — 자녀, 가족, 자경단원
3. **공식 번호로 직접 확인** — 본인이 검색한 번호로
4. **신고하기** — 112 또는 118(스미싱 신고)
5. **속으셨을 때는 즉시 은행에 전화해서 지급 정지** — 한 시간 안에 막으면 돈 돌려받을 수 있어요

## 4. 자주 쓰이는 사기 키워드

다음 단어가 들어간 메시지는 **거의 다 사기**입니다.

- "안전계좌"
- "본인 인증을 위해 비밀번호"
- "환급금"
- "당첨"
- "저금리 대출"
- "폰 액정"
- "긴급 본인 인증"
- "행정처분"
- "개인정보 유출"

진짜 기관은 이렇게 합니다.

## 막히셨을 때

| 증상 | 해보실 것 |
|------|----------|
| 이미 링크를 눌렀어요 | 즉시 휴대폰을 인터넷과 분리(비행기 모드)하시고 자녀·자경단원에게 도움 요청. |
| 이미 돈을 보냈어요 | 즉시 본인 은행에 전화 → "지급 정지" 요청. 1시간 안에 빠르면 돌려받을 수 있어요. 동시에 112에 신고. |
| 어떤 게 진짜인지 헷갈려요 | 사기로 추정해 주세요. 진짜라면 기다려도 다시 연락 옵니다. |

## 노묘 트랙은 여기까지입니다
