# 노묘 트랙 — 1장. 컴퓨터 처음 켜기와 끌기

> 컴퓨터를 켜고 끄는 가장 기본적인 방법입니다. 이것만 익히셔도 첫 단추는 끼우신 거예요.

이 챕터는 **20분**이면 끝납니다.

---

## 시작 전에

컴퓨터는 무섭게 생기지 않았습니다. **전원 버튼만 누르면 켜지고, 메뉴 한 번 누르면 꺼집니다.** 휴대폰 켜고 끄시는 거랑 비슷해요.

---

## 1. 전원 버튼 찾기

전원 버튼은 보통 **동그라미에 세로 막대**가 그려진 모양입니다. ⏻

| 컴퓨터 종류 | 전원 버튼 위치 |
|------------|---------------|
| 노트북 | 키보드 위쪽 가운데 또는 오른쪽 위 |
| 데스크톱 본체 | 본체 앞면 위쪽 |
| 모니터 | 화면 아래쪽 또는 뒤쪽 (본체와 별도) |

> [!TIP]
> 데스크톱은 **본체와 모니터를 둘 다** 켜셔야 합니다. 본체만 켜면 화면이 안 보여요.

## 2. 전원 켜기

전원 버튼을 **한 번 살짝 누르고 떼주세요.** 길게 누르실 필요 없습니다.

켜지면 컴퓨터에서 작은 소리(부팅음)가 나고, 화면에 글자나 그림이 뜨기 시작합니다. 이게 30초~2분 정도 걸려요. **기다려 주시면 됩니다.**

## 3. 비밀번호 입력

화면에 비밀번호 입력 칸이 뜨면, 본인이 정한 비밀번호를 키보드로 입력해 주세요. 보호자가 정해주신 컴퓨터라면 보호자께 여쭤보시면 됩니다.

> [!IMPORTANT]
> 비밀번호는 종이에 적어두시거나 휴대폰 메모장에 적어두세요. 잊으시면 다시 만들기 번거로워집니다. 7장에서 안전한 비밀번호 만드는 법을 배우실 거예요.

비밀번호 없이 켜지는 컴퓨터도 있습니다. 그러면 그냥 다음 단계로.

## 4. 바탕화면 만나기

비밀번호 입력 후 잠시 기다리시면, **바탕화면**이라는 곳에 도착합니다. 이게 컴퓨터의 "거실" 같은 곳이에요.

바탕화면에는 보통:
- 그림 한 장 (배경)
- 작은 아이콘들 (휴지통, 인터넷 브라우저 등)
- 화면 아래쪽에 막대(작업 표시줄)

축하드립니다. 이제 컴퓨터에 들어오셨어요.

## 5. 컴퓨터 끄기 — 정상적인 방법

전원 버튼으로 그냥 끄시면 안 됩니다 (그건 컴퓨터에 안 좋아요). 메뉴로 끄셔야 합니다.

### Windows의 경우

1. 화면 왼쪽 아래 **윈도우 모양 아이콘** (⊞)을 클릭
2. 작은 메뉴가 뜨면 **전원** 모양 아이콘 클릭
3. **시스템 종료** 선택

### Mac의 경우

1. 화면 왼쪽 위 **사과 모양 아이콘** (🍎) 클릭
2. **시스템 종료...** 선택
3. 다시 **시스템 종료** 버튼 누르기

화면이 까매지면서 컴퓨터가 꺼집니다. 1~2분 기다리시면 모든 게 정리돼요.

## 6. 절대 하지 마실 것

- 컴퓨터가 켜져 있는데 **전원 버튼을 길게 눌러서 강제로 끄기** (꼭 필요한 응급 상황 외에는 NO)
- 노트북을 **켜진 채로 가방에 넣기**
- 컴퓨터를 **물 가까이에 두기**
- 모르는 알림창에서 아무 버튼이나 누르기 (의심되시면 디스코드 #도와줘에 물어봐 주세요)

## 막히셨을 때

| 증상 | 해보실 것 |
|------|----------|
| 전원 버튼을 눌렀는데 안 켜져요 | 전원 코드가 꽂혀 있나요? 노트북은 충전선이 꽂혀 있나요? |
| 화면이 까매요 | 모니터(데스크톱) 전원이 꺼져 있을 수 있어요. 모니터 버튼도 한 번 눌러보세요. |
| 비밀번호를 잊었어요 | 가족이나 자경단 디스코드 #도와줘 채널에 도움 요청. 본인 외 다른 사람이 컴퓨터에 들어가지 못하게 하기 위해 비밀번호 재설정은 신중히. |
