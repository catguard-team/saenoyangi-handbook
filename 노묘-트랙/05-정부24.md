# 노묘 트랙 — 5장. 정부24 들어가기

> 주민등록등본·인감증명 같은 서류를 집에서 떼시는 법입니다. 주민센터 안 가셔도 됩니다.

이 챕터는 **30분**이면 끝납니다. 처음에는 시간이 걸려도 괜찮습니다.

---

## 시작 전에

정부24는 정부에서 운영하는 **공식 사이트**입니다. 등본·초본·여러 증명서를 집에서 발급받으실 수 있어요. 주민센터까지 가시는 시간을 아껴드립니다.

> [!CAUTION]
> 정부24를 흉내 낸 **가짜 사이트**가 있습니다. 반드시 정확한 주소(`gov.kr`)로 들어가셔야 합니다. 광고 결과를 클릭하지 마시고, 직접 주소를 입력해 주세요.

---

## 1. 준비물

다음을 가까이에 두세요.

- **휴대폰** (본인 인증에 사용)
- **공동인증서** 또는 **간편 인증** (네이버·카카오·PASS 중 하나)

공동인증서가 없으셔도 괜찮습니다. **간편 인증**으로 더 편하게 하실 수 있어요.

## 2. 정부24 들어가기

브라우저 주소창에 정확히 입력해 주세요.

```
gov.kr
```

또는

```
www.gov.kr
```

> [!IMPORTANT]
> 검색창에 "정부24"라고 치셔서 들어가시는 건 위험할 수 있어요. 광고 사이트가 위에 뜰 수 있습니다. **주소창에 직접** `gov.kr`이라고 치시는 게 가장 안전합니다.

## 3. 자물쇠 표시 확인

페이지가 열리면 **주소창 옆에 자물쇠(🔒) 표시**가 있는지 확인해 주세요. 자물쇠가 있으면 안전한 사이트입니다.

또 화면에 **"정부24"** 로고와 **"정부에서 운영합니다"** 같은 안내가 있어야 진짜입니다.

## 4. 자주 쓰시는 서류 — 주민등록등본 떼기

정부24 메인 화면에 **"자주 찾는 서비스"** 같은 메뉴가 있어요. 그 안에 **주민등록등본(초본)** 이 있습니다.

1. **주민등록등본(초본)** 클릭
2. **신청하기** 또는 **발급하기** 버튼 클릭
3. 본인 인증 방법 선택 — **간편 인증**을 추천드립니다 (휴대폰 앱으로 5초)
4. 휴대폰의 네이버·카카오·PASS 앱으로 인증
5. 신청 정보 확인 (주소, 발급 목적 등)
6. **발급** 버튼

발급된 서류는 **PDF**로 화면에 뜹니다. **인쇄**하시거나 컴퓨터에 저장하실 수 있어요.

## 5. 간편 인증 하는 법

처음 보시면 헷갈리실 수 있는데, 이렇게 하시면 됩니다.

1. **간편 인증** 선택 → 본인이 쓰시는 앱(네이버·카카오·PASS) 고르기
2. 화면에 **이름·휴대폰 번호·생년월일** 입력
3. **인증 요청** 클릭
4. 휴대폰에서 알림이 와요. 휴대폰 앱 열고 **확인**

이게 끝입니다. 한 번 해 보시면 다음부터는 1분도 안 걸려요.

## 6. 다른 자주 쓰시는 서류

- **건강보험 자격득실 확인서** — 건강보험공단(`nhis.or.kr`)에서
- **소득금액증명** — 홈택스(`hometax.go.kr`)에서
- **자동차 등록증** — 정부24
- **출입국 사실 증명** — 정부24

> [!TIP]
> 어떤 서류가 필요하실 때 정부24의 **"민원 검색"** 칸에 그 이름을 치시면 안내가 나옵니다.

---

## 안전 수칙 (꼭 봐주세요)

> [!CAUTION]
> 정부24는 **돈을 받지 않습니다**. 발급 수수료는 무료이거나 매우 적은 금액(주민등록등본은 무료)입니다. 갑자기 큰 금액을 입금하라고 하면 100% 사기입니다.
>
> "정부24 본인 인증을 위해 비밀번호를 알려주세요" 같은 전화나 문자를 받으시면, 절대 알려주지 마세요. 정부에서는 절대 그런 식으로 묻지 않습니다.

의심스러우신 일이 있으시면 **자녀나 자경단원**에게 먼저 보여드리세요.

## 막히셨을 때

| 증상 | 해보실 것 |
|------|----------|
| 본인 인증이 안 돼요 | 휴대폰 번호와 생년월일이 정확한지 확인. 휴대폰 앱(네이버 등)에 로그인되어 있는지 확인. |
| 서류가 안 보여요 | PDF 뷰어가 필요할 수 있어요. 보통 자동 설치됩니다. 안 되시면 자녀나 자경단원에게 도움 요청. |
| 인쇄가 안 돼요 | 프린터가 컴퓨터와 연결되어 있는지 확인. 없으시면 PDF로 저장하셨다가 가족에게 부탁드리시면 됩니다. |
