# 노묘 트랙 — 6장. 카카오톡 PC 버전 설치

> 휴대폰의 카카오톡을 컴퓨터에서도 쓰실 수 있게 합니다. 큰 화면으로 글 쓰시면 훨씬 편해요.

이 챕터는 **20분**이면 끝납니다.

---

## 시작 전에

휴대폰의 카카오톡 글자가 작아 답답하시죠? **카카오톡 PC 버전**을 깔으시면 컴퓨터의 큰 화면에서 같은 메시지를 보고 답하실 수 있습니다. 휴대폰과 컴퓨터가 동시에 켜져도 괜찮아요. 둘 다 같은 메시지가 들어옵니다.

---

## 1. 다운로드 페이지 들어가기

브라우저 주소창에 정확히 입력해 주세요.

```
www.kakaocorp.com/page/service/service/KakaoTalk
```

또는 검색창에 "카카오톡 PC 다운로드"라고 치시고, **반드시 "kakaocorp.com"** 이 들어간 결과를 클릭하세요.

> [!CAUTION]
> 카카오톡 다운로드를 흉내 낸 **가짜 사이트**가 많이 있습니다. 광고 결과는 클릭하지 마시고, 주소가 `kakaocorp.com`인지 한 번 더 확인해 주세요.

## 2. 본인 컴퓨터에 맞는 버전 받기

페이지에서 본인 컴퓨터에 맞는 버튼을 클릭하세요.

- Windows를 쓰시면 → **Windows용 다운로드**
- Mac을 쓰시면 → **Mac용 다운로드**

다운로드가 시작됩니다 (보통 1분 안에 끝나요).

## 3. 설치하기

### Windows

1. 화면 아래쪽 또는 브라우저 우상단의 다운로드 표시에서 **KakaoTalk_Setup.exe** 같은 파일을 더블 클릭
2. **"이 앱이 디바이스를 변경하도록 허용하시겠습니까?"** 알림이 뜨면 **예** 클릭
3. 설치 안내가 뜹니다. **다음 → 동의 → 다음 → 설치** 순서로 진행
4. 끝나면 바탕화면에 **카카오톡** 아이콘이 생깁니다

### Mac

1. 다운로드한 `KakaoTalk.dmg` 파일 더블 클릭
2. 작은 창이 뜨면 **카카오톡 아이콘을 응용 프로그램 폴더로 드래그**
3. 응용 프로그램에서 카카오톡 아이콘 더블 클릭하시면 시작

## 4. 로그인

카카오톡 PC 버전이 열리면 로그인 화면이 뜹니다.

### 휴대폰 카카오톡으로 빠르게

1. **QR 코드로 로그인** 클릭
2. 화면에 큰 QR 코드(네모 무늬)가 뜸
3. 휴대폰 카카오톡 → **친구 검색** 옆 QR 아이콘 → 화면의 QR 찍기
4. 휴대폰에 알림 → **로그인 허용**

### 이메일·비밀번호로

1. 카카오 계정 이메일과 비밀번호 입력
2. 휴대폰으로 인증 코드 받기
3. 코드 입력하시면 로그인

## 5. 잘 작동하는지 확인

로그인 후 **친구 목록**과 **채팅방**이 휴대폰과 똑같이 보이면 OK입니다.

연습:
- 채팅방 하나 클릭해서 메시지 한 줄 보내보기
- 휴대폰에서도 같은 메시지가 보이는지 확인

## 6. 컴퓨터 큰 화면의 장점

- **타자가 더 편합니다** — 키보드는 휴대폰보다 빠르고 정확해요
- **사진을 한 번에 여러 장** 보내실 수 있어요
- **파일·문서**를 보낼 때 편해요 — 컴퓨터 안 파일을 바로 보내기 가능
- **눈이 덜 피곤해요** — 큰 화면에 큰 글자

---

## 안전 수칙

> [!IMPORTANT]
> 다른 사람이 본인 컴퓨터를 쓰시는 환경(공용 컴퓨터, 가족과 함께 쓰는 컴퓨터)에서는 **로그아웃**을 꼭 해주세요. 카톡에는 사적인 대화가 많이 들어 있어요.
>
> 로그아웃: 카카오톡 우상단 톱니바퀴 → **로그아웃**

또 카카오톡을 사칭한 사기 메시지가 많아요. 8장에서 자세히 다룹니다.

## 막히셨을 때

| 증상 | 해보실 것 |
|------|----------|
| 다운로드가 안 돼요 | 인터넷 연결 확인. 브라우저를 한 번 닫고 다시 시도. |
| 설치 중 오류가 떠요 | 컴퓨터를 한 번 껐다 켜고(재시작) 다시 설치. 안 되시면 자녀·자경단에 도움 요청. |
| QR 로그인이 안 돼요 | 휴대폰 카카오톡 앱이 최신 버전인지 확인. 또는 이메일 로그인으로 시도. |
