# 새끼고양이 핸드북 (saenoyangi-handbook)

> 자경단에 갓 합류하신 새끼고양이(=신참) 분들을 위한 학습 가이드입니다. 4개 트랙으로 구성되어 있고, 본인에게 맞는 골목부터 시작하시면 됩니다.

자경단은 별도 조건이 없습니다. 컴퓨터 처음 켜시는 노묘분도, 키오스크에 막히신 자영업자분도, 코딩을 처음 시작하시는 어린이도 — 모두 새끼고양이입니다. 첫 쥐돌이는 작아도 괜찮습니다.

행동강(綱)냥(領) **4조 — 신참 보호**: *RTFM·텃세 금지.*

---

## 4개 트랙

| 트랙 | 폴더 | 누가 보면 좋나 |

## 학습 원칙

- **완벽보다 시작.** 챕터 1개를 끝내는 게 책 한 권 사두고 안 보는 것보다 낫습니다.
- **첫 쥐돌이를 부끄러워하지 않습니다.** 작은 결과물도 [`jwidori`](https://github.com/catguard-team/jwidori)에 자랑해 주세요.
- **막히실 때는 디스코드.** 자경단은 [디스코드 #도와줘](https://discord.gg/Dp4pKwns2Y) 채널에서 멘토링하고 있습니다.
- **그만두실 자유.** 진도가 안 나가셔도 추적하지 않습니다. 다른 트랙으로 옮기셔도 괜찮아요.

## 멘토 자경단원분들께

- **"문서 읽으세요"는 답이 아닙니다.** 어떤 문서, 어디부터, 왜 그 부분인지 알려드려 주세요.
- **새끼고양이의 첫 질문은 항상 옳습니다.** 비웃지 마세요. 우리 모두 한 번은 모르는 사람이었습니다.
- **개인정보는 절대 받지 마세요.** 실명·주소·학교·연락처 받지 않습니다. [`manifesto/SAFETY.md`](https://github.com/catguard-team/manifesto/blob/main/SAFETY.md) 참조해 주세요.
- **공개 동의는 작성 동의와 별개입니다.** 미성년자·결정 보조가 필요한 학습자의 결과물 공개 전에는 보호자 동의를 한 번 더 받아주세요. → [`SAFETY-NOTES.md`](./SAFETY-NOTES.md)
