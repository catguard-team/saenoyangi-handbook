# 새끼고양이 핸드북 (saenoyangi-handbook)

> 자경단에 갓 합류한 새끼고양이(=신참)를 위한 학습 가이드. 4개 트랙. 본인에게 맞는 골목부터.

자경단은 조건 없습니다. 컴퓨터 처음 켜는 노묘도, 키오스크에 막힌 자영업자도, 코딩 처음 시작하는 어린이도 — 모두 새끼고양이입니다. 첫 쥐돌이는 작아도 됩니다.

행동강(綱)냥(領) **4조 — 신참 보호**: *RTFM·텃세 금지.*

---

## 4개 트랙

| 트랙 | 폴더 | 누가 보면 좋나 |
|------|------|----------------|
| 🧓 [노묘 트랙](./노묘-트랙/) | 컴퓨터 처음 켜는 어르신 | 폰만 쓰던 분, 키오스크 막막한 분 |
| 🐾 [어린이 트랙](./어린이-트랙/) | 코딩 처음 시작하는 어린이·청소년 | 학교 코딩 수업이 어렵게 느껴지는 친구 |
| 🛒 [자영업자 트랙](./자영업자-트랙/) | 가게 운영 디지털 도구 | 사장님인데 컴퓨터로 뭘 더 할 수 있는지 모를 때 |
| ♿ [접근성 트랙](./접근성-트랙/) | 장애가 있어도 코딩하기 | 시각·청각·운동·인지 접근성 도구 |

각 트랙은 **0번 챕터(준비물)** 부터 시작합니다.

> [!TIP]
> GitHub이 처음이세요? 자경단 문서는 다 GitHub에 있습니다. 회원가입·2FA·이슈·첫 PR까지 모두 단계별로: [`GITHUB-GUIDE.md`](./GITHUB-GUIDE.md). 설치할 것 없이 브라우저만으로 가능.

## 학습 원칙

- **완벽보다 시작.** 챕터 1개를 끝내는 것이 책 한 권 사두고 안 보는 것보다 낫습니다.
- **첫 쥐돌이를 부끄러워하지 않는다.** 작은 결과물도 [`jwidori`](https://github.com/catguard-team/jwidori)에 자랑.
- **막히면 디스코드.** 자경단은 [디스코드 #도와줘](https://discord.gg/Dp4pKwns2Y) 채널에서 멘토링.
- **그만둘 자유.** 진도 안 나가도 추적 안 합니다. 다른 트랙으로 옮겨도 OK.

---

## 멘토 자경단원에게

- **RTFM 금지.** "문서 읽으세요"는 답이 아닙니다. 어떤 문서, 어디부터, 왜 그 부분인지 알려주세요.
- **새끼고양이의 첫 질문은 항상 옳다.** 비웃지 마세요. 본인도 한 번은 모르는 사람이었습니다.
- **개인정보 절대 받지 않기.** 실명·주소·학교·연락처 받지 마세요. [`manifesto/SAFETY.md`](https://github.com/catguard-team/manifesto/blob/main/SAFETY.md).
- **공개 동의는 작성 동의와 별개.** 미성년자·결정 보조 필요 학습자의 결과물 공개 전 보호자 동의 한 번 더. → [`SAFETY-NOTES.md`](./SAFETY-NOTES.md)
